❓ Help & Documentation

Getting Started
1. Download Documents from N26
  1. Open N26 mobile app
  2. Tap your profile picture (top-right)
  3. Select "Support Center" → "Messages from N26"
  4. Download all: buy_order_, sell_order_, income_distribution_ documents

Note: This can be slow on mobile. Consider using the web version.

2. Upload to This Tool
  1. Go to Home
  2. Drag-and-drop all PDF files (or click to browse)
  3. Click "Analyze Documents"
3. Download Tax Report
  1. Results will show key metrics and files
  2. Download the tax_report.xlsx file
  3. Use it for your tax filing or share with your tax advisor
Understanding the Report
Excel File Contents
  • Declarations - Summary of tax form boxes (2042, 2047, 2074)
  • Transactions - Detailed list of all buys, sells, and dividends
Key Tax Boxes (French Tax)
2042 Box 2DC Dividend income
2042 Box 3VG Capital gains (positive)
2042 Box 3VH Capital losses (negative)
2042 Box 8VL Foreign tax credits
Troubleshooting
❌ "OCR Failed" Error

The PDF could not be read. This might happen if:

  • File is corrupted or incomplete
  • File is from an unusual document format
  • Solution: Try re-downloading the document from N26
❌ "Data Not Found" Error

Expected fields couldn't be located. This might mean:

  • Document is from an older N26 format
  • It's not a standard transaction/dividend statement
  • Solution: Verify the document matches expected N26 layout
❌ "No Valid Documents Found"

Uploaded files don't match N26 naming patterns.

  • Expected filenames start with: buy_order_, sell_order_, income_distribution_
  • Solution: Check filenames match and re-upload
Before Filing
  • ✅ Always verify the report matches your N26 annual tax statement
  • ✅ Review all transaction dates and amounts
  • ✅ Check for any errors or unusual entries
  • ✅ Cross-check capital gains/losses calculation
  • ✅ Consult with a tax advisor if unsure about any values
