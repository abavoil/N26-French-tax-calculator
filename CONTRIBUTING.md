# Contributing to N26 Tax Calculator

Thank you for your interest! This is a simple personal project, so contributions are welcome but informal.

## Areas for Contribution

- Bug fixes
- Improved error messages
- Better documentation
- Performance improvements
- Test coverage

## Branches

- `main` - Stable, production-ready
- `copilot-refactor` - Work-in-progress refactoring with new UI

## How to Contribute

1. Fork the repo
2. Create a feature branch: `git checkout -b feature/my-improvement`
3. Make your changes
4. Test locally
5. Submit a pull request

## Code Style

- Follow PEP 8
- Use meaningful variable names
- Keep functions small and focused
- Add docstrings to functions

## Testing

Before submitting:
```bash
python -m pytest
flake8 . --max-line-length=100
```

## Questions?

Open an issue on GitHub to discuss ideas before starting work.
